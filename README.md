## 🧠 IA para Análisis de Feedback de Usuarios – Experiencias tipo UBER
# User Feedback Analysis AI – UBER-like Experiences

Este proyecto desarrolla una inteligencia artificial especializada en analizar comentarios y valoraciones de usuarios, enfocándose en identificar insights clave sobre experiencias en plataformas tipo UBER. El objetivo es clasificar, resumir y entender el feedback para mejorar decisiones de producto.
Se utiliza un dataset curado de comentarios y valoraciones de usuarios que relatan experiencias con viajes, conductores, tiempos de espera y calidad del servicio. Este dataset ha sido preprocesado y etiquetado para tareas de clasificación de sentimiento, tópicos y detección de problemas.

-------------------------------
This project builds an AI system specialized in analyzing user feedback, with a focus on extracting key insights from UBER-like platform experiences. The goal is to classify, summarize, and understand feedback to support product decision-making.
A curated dataset of user comments and ratings describing experiences with rides, drivers, waiting times, and service quality is used. The dataset has been preprocessed and labeled for sentiment classification, topic modeling, and issue detection tasks.

-------------------------------
